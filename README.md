# 🎵 Spotify Clone

A modern **Spotify-inspired music streaming UI** built using **React.js and Vite**. This project recreates the look and feel of Spotify with a clean, responsive interface and reusable React components.

🔗 **Live Demo:** [Spotify Clone](https://spotify-clone-iota-topaz.vercel.app/)

🔗 **GitHub Repository:** [Spotify-Clone](https://github.com/hemarukesh/Spotify-Clone)

---

## 📌 About the Project

The **Spotify Clone** is a frontend web application developed to practice and demonstrate modern React.js development.

The project focuses on creating a music-streaming interface inspired by Spotify, including a visually appealing layout, reusable components, navigation, and responsive design.

This project helped me strengthen my understanding of:

* React.js
* Component-based development
* Vite
* JavaScript
* Responsive UI design
* Modern frontend development

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/hemarukesh/Spotify-Clone.git
```

### 2. Navigate to the project directory

```bash
cd Spotify-Clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

After starting the development server, open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```
